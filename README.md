# Лабораторна робота №5 — варіант 5

ByteMarket: сторінка форм на основі лабораторної №4. Відкрийте `forms.html` у браузері або запустіть `python3 -m http.server 8055` у папці проєкту.

Форма перевіряє ім’я, email, телефон, кількість, опис і підтвердження; показує прогрес, запас та локальний підсумок. Запити з даними форми на сервер не надсилаються. Список товарів фільтрується пошуком. Кнопка «Очистити» скидає форму.

Додано `forms.html`, `assets/css/forms.css`, `assets/js/forms.js`; на всіх сторінках є посилання «Форми». Таблиця варіанта 5 з лабораторної №4 збережена.

У навчальному розділі наведено застарілий `keygen` і правила звукового CSS, які вимагає методичка. `keygen` не генерує ключів у сучасному браузері; звукові правила є прикладом старої специфікації та не запускають аудіо. Джерела: [WHATWG](https://html.spec.whatwg.org/multipage/obsolete.html#non-conforming-features), [W3C CSS2](https://www.w3.org/TR/CSS2/aural.html).

Звіт: `report/lab5-htmlcss-variant5.pdf`.
